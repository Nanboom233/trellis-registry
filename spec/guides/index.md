# Collaboration Guides

These guides apply to planning, agent coordination, tools, Git operations, and project text.

## Pre-Development Checklist

- Read [Planning](planning.md) before you define or change a task.
- Read [Agent Coordination](agent-coordination.md) when the workflow uses subagents.
- Read [Tool Use](tool-use.md) before file, IDE, credential, or patch operations.
- Read [Writing](writing.md) before you change project text.
- Read [Git Workflow](git-workflow.md) before commits, branches, or task archive operations.

## Quality Check

Check the applicable guides against the actual work and authorization.
Use the task context manifests to select the required guideline files for subagents.
An index points to guidelines. It does not replace their contents.
