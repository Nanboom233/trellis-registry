# Engineering Rules

These rules apply across languages and application layers.

## Pre-Development Checklist

- Read [Architecture](architecture.md) for ownership and module changes.
- Read [Data Contracts](data-contracts.md) for input, storage, or cross-layer data changes.
- Read [Errors and Logging](errors-and-logging.md) for failure, retry, or diagnostic changes.
- Read [Testing](testing.md) before verification or test changes.

## Quality Check

Use the applicable guideline files to check behavior, contract ownership, error handling, and verification evidence.
Use the project's existing quality commands.
Reuse valid results under the conditions in [Testing](testing.md).
