# Language Rules

Select the guideline for each language that the task changes.

## Pre-Development Checklist

- [Python](python.md): typing, function boundaries, imports, and diagnostics.
- [Java](java.md): contracts, method boundaries, nullability, and framework constraints.
- [TypeScript](typescript.md): types, imports, names, and exports.
- [Go](go.md): formatting and project checks.

For React code, also read [React](../ui/react.md).
For build scripts, also read the applicable [Build Rules](../build/index.md).

## Quality Check

Check the changed code against its language guideline.
Preserve the conditions and exceptions stated in that guideline.
Use the existing project commands for the affected language.
