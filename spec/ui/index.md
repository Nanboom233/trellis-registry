# UI Rules

These rules apply to visible interfaces and their interactions.

## Pre-Development Checklist

- Read [Design](design.md) for content, structure, styling, and interaction changes.
- For Web interfaces, read [Accessibility](accessibility.md).
- For React code, read [React](react.md) and [TypeScript](../languages/typescript.md).

## Quality Check

Inspect the actual render and exercise the key interactions.
Check the applicable design and accessibility rules against the visible result.
Preserve the approved structure and design tokens for style-only work.
