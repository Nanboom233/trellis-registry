# React

Use `useState` for local component state.
Compute derived data instead of storing a duplicate state value.
Reuse existing data-fetching hooks.
Do not add a state library without a current need.
Preserve the actual owner of shared state.

For projects that already use Tailwind, `cn`, and CVA, use that styling stack.
Use utility classes, `cn`, and CVA for applicable styling and variants.
Do not use inline styles or CSS Modules in those projects.
Do not impose that dependency stack on other projects.
